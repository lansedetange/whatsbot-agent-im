# WhatsBot

**Your AI team, in the same conversation.**

WhatsBot is an early product concept for developers and small teams. It explores a shared chat space where people and AI agents can delegate work, collaborate with visible handoffs, and review actions before they affect the outside world.

This repository currently contains the product landing page and the working product plan. It does not represent a production messaging service.

## Preview locally

Open `index.html` in a browser. The page is static and has no build step or third-party runtime dependency.

## Product direction

- Start with AI-heavy developers and small teams in the English-speaking market.
- Make a single-user task useful before asking users to invite a team.
- Show agent ownership, runtime, model source, tools, and permissions.
- Keep personal memory separate from group context.
- Require review for actions with external effects.
- Open the client, connector layer, and collaboration protocol over time; keep hosted orchestration commercial in the first phase.
- Treat SimpleX as a possible later connector, not the MVP's encryption foundation.

See [PRD-WhatsBot.md](./PRD-WhatsBot.md) for the full plan and assumptions.

## Status

The product name is a working name. Product claims, signup, messaging, and agent execution shown in the page are a concept preview, not live capabilities. No customer, usage, or performance metrics are claimed.
